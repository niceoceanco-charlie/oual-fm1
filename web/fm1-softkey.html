FM-1 soft key

Sends the one message F0 22 24 35 7D F7 to an FM-1, once. The FM-1 then goes black and restarts into the chip's own update mode (USB id 4C4A:8057, "WL82 UBOOT1.00"). It writes nothing to the FM-1. Switching the FM-1 off and on again brings its firmware back.

Before it sends, this page asks the FM-1 for its identity (a read-only question) and refuses unless it answers as an FM-1. It uses the one MIDI output whose name contains "FM-1" or "FM1" and ignores every other device. Use Chrome, open this file from disk, and start your recovery tool first: the Mac gives the update mode up after about 30 seconds if nobody takes it.

Type UBOOT to enable the button.
